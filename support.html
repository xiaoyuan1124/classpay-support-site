使用支援與常見問題

ClassPay 主要協助個人老師管理學生、課程堂數與收款紀錄，沒有自動扣款、收款代辦或金流功能。

如何備份資料？

開啟「資料管理」→「建立備份」，再從 iOS 分享視窗選擇「儲存到檔案」。請將 JSON 檔保存在可靠位置，並避免傳給無關人士。

如何還原？

在「資料管理」選擇「從備份還原」，選取 ClassPay JSON 備份。先檢視備份日期與紀錄數量，確認後才取代目前裝置內的資料。建議還原前先另存現有備份。

CSV 與 JSON 有何差別？

CSV 可用試算表查看堂數與收費摘要，但不保留完整上課／付款稽核資料；只有 ClassPay 格式的 JSON 備份能用於資料還原。

付款紀錄輸入錯了怎麼辦？

在學生的課程包中找到付款紀錄，選擇撤銷並確認。ClassPay 會保留原始金額與日期作為稽核，待收金額自動更新。此操作僅修正記帳，不會向學生退款。

課堂誤扣或排課取消怎麼辦？

已完成的課可使用紀錄中的撤銷功能還原堂數；尚未完成的已排課課程，可在相應操作流程取消，不會扣除堂數。

換手機後資料會自動同步嗎？

目前沒有自動跨裝置同步。請先從舊裝置匯出 JSON 備份，再於新裝置還原。請勿依賴 CSV 作為備份。
